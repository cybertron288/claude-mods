# claude-mods

Custom Claude Code mods. One directory per mod.

| Mod | Description |
|-----|-------------|
| [yt-music](./yt-music) | YT Music in Chrome above the prompt: track, time, play/pause, previous, next and seek |

## Install

```
/plugin marketplace add cybertron288/claude-mods
/plugin install yt-music@ravi-mods
```
